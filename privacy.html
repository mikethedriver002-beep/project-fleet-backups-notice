Project Fleet Backups: privacy notice

Updated October 17, 2026. This application is for its owner's private, personal backup use; it is not offered as a public service.

Access and use

The rclone uploader uses Google's drive.file permission to create, read and verify backup files and folders used with this app. It does not request access to unrelated Drive files. Backup contents are transferred to the owner's Google Drive for storage and recovery, not published on this site.

Storage and control

OAuth credentials remain in private local/server configuration. Backups are retained according to the owner's instructions; no automatic deletion is implied. The owner can revoke this app through Google Account connections and manage retained files in Google Drive. Revoking access does not itself delete existing backups.

Other uses and this website

The backup uploader does not sell backup data, perform advertising, or train models on it. This static notice adds no analytics, forms or tracking scripts. GitHub hosts this website and processes hosting requests under its privacy statement. Google's services remain subject to Google's policies.
